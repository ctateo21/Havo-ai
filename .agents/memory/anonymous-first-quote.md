---
name: Anonymous first quote
description: Product scope for value-before-contact access and draft preservation
---
Visitors get one property without personal details. Edits, return visits, and switching tools for that same property belong to the first quote; another property requires an account.

**Why:** Christian wants people to see the calculation's value before providing information. His production follow-up explicitly permits choosing a rule that lets a guest try another tab for the same property; tool switching must not strand that property's quote.

**How to apply:** Require a real account for saves, downloads, sharing/email, additional quotes, and live carrier requests. Preserve drafts through sign-up and failed saves. Never use a local logged-in flag as authorization, and never send anonymous calculations to CRM. Keep marketing consent separate and unchecked.
